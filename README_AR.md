# تطبيق أسطول وصيانة — مشروع Android

المشروع عبارة عن تطبيق أندرويد يعمل دون اتصال بالإنترنت ويعرض تطبيق الصيانة المرفق داخل WebView محلي.

## الميزات الحالية
- إدارة القواطر وإضافة/تعديل/حذف
- تسجيل الصيانة، التاريخ، قراءة العداد، نوع الصيانة، القطع والتكلفة
- تنبيه زيت بناءً على 4000 كم من آخر تغيير
- بحث وتقارير وتصفية وطباعة
- نسخ احتياطي JSON واستعادة
- شعار مخصص واسم عربي

## بناء APK
1. افتح Android Studio (نسخة حديثة).
2. اختر Open وافتح مجلد `FleetMaintenanceAndroid`.
3. انتظر مزامنة Gradle وتثبيت SDK 35 إذا طلبه البرنامج.
4. من القائمة Build اختر Build APK(s).
5. ملف APK الناتج عادةً: `app/build/outputs/apk/debug/app-debug.apk`

## مزامنة عدة أجهزة (المرحلة التالية)
هذه النسخة محلية ولا تحتوي مزامنة سحابية بعد. إضافة مزامنة تتطلب backend/حسابات، قاعدة بيانات مشتركة، مصادقة، وسياسة حل تعارضات البيانات. يمكن تنفيذها لاحقاً باستخدام Firebase أو Supabase. لا تُدخل بيانات حقيقية في نسخة تجريبية قبل إضافة المصادقة والحماية.

## تنبيه
بيانات التطبيق المحلية تحفظ في مساحة المتصفح/WebView. احتفظ بنسخة احتياطية JSON بانتظام.
